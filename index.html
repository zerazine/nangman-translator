낭만타우렌 와우 포에버 번역기

북미 서버 영어 채팅을 게임 위에서 바로 한국어로 보고, 한국어로 치면 영어로 보내 주는 무료 번역 프로그램입니다. 번역은 내 PC 안에서 돌아가서 돈이 들지 않습니다.

저작권내 PC 단계설치처음 설정사용법업데이트자주 묻는 문제삭제문의후원

저작권 안내

본 북미섭 와우 포에버 전용 번역프로그램의 저작권은 제작자 낭만타우렌 (배틀태그 하르만#31615)에 있으며 어떤 방식으로도 수정과 재배포가 불가합니다.

1내 PC는 어느 단계?

그래픽카드 메모리에 따라 세 가지 중 하나를 받습니다. 기준은 와우를 켜 둔 채로 번역이 돌아가는가입니다.

버튼 한 번으로 확인

받기 전에 눌러 보세요. 브라우저가 알려 주는 그래픽카드 이름으로 단계를 추천합니다. 아무것도 받거나 설치하지 않습니다.

직접 확인하는 법 (작업 관리자)

  1. 키보드에서 Ctrl + Shift + Esc → 작업 관리자
  2. 위쪽 성능 탭 → 왼쪽 아래 GPU
  3. 오른쪽의 전용 GPU 메모리 숫자 (예: 12.0GB)

숫자가 16GB 이상이면 고급, 10~12GB면 중간, 그보다 작으면 최저를 받으세요. AMD 그래픽카드는 최저 단계를 권합니다. 설치할 때도 설치 파일이 한 번 더 확인해 줍니다.

2설치하기

추천고급 · Gemma 4약 6.5GB · 그래픽 메모리 16GB 이상받기 추천중간 · Qwen3약 4.1GB · 그래픽 메모리 10~12GB받기 추천최저 · Gemini수십 MB · 그래픽카드 상관없음받기
  1. zip 받기 — 내 단계에 맞는 zip을 구글 드라이브에서 받습니다.
  2. 압축 끝까지 풀기 — zip을 오른쪽 클릭 → 모두 압축 풀기. zip 안에서 바로 실행하면 안 됩니다.
  3. 설치.exe 두 번 클릭 — 그래픽카드와 와우 포에버 설치 위치를 스스로 찾고, 필요한 것(Ollama·번역 모델·인게임 애드온)을 알아서 설치합니다. 손댈 것 없이 기다리면 됩니다.
  4. 최저 단계만 — Gemini 키를 넣는 창이 뜹니다. 아래 Gemini 키 받는 법을 보세요.
  5. 완료 — "와우를 켜고 /reload 하세요" 안내가 나오면 끝입니다. 바탕화면에 바로가기가 생깁니다.
프로그램은 C:\낭만타우렌_번역기 에 설치되고, 바탕화면에는 바로가기만 생깁니다.

Gemini 키 받는 법 (최저 단계)

Gemini는 구글의 번역 AI입니다. 키를 넣으면 번역기가 구글 서버로 채팅을 보내 번역합니다. 무료로도 쓸 수 있지만, 하루에 보낼 수 있는 양이 정해져 있어서 공개 채널까지 다 번역하면 금방 막힙니다. 오래 쓰실 거면 유료(결제 등록)를 권합니다.

예상 금액 (유료일 때)

번역기는 한 줄을 번역할 때 와우 용어 사전·말투 지시문을 같이 보내서, 한 줄에 대략 입력 2,000토큰 + 출력 40토큰쯤 씁니다. Gemini 3.5 Flash-Lite 유료 가격(입력 100만 토큰당 0.30달러 · 출력 100만 토큰당 2.50달러)으로 계산하면 한 줄에 약 1원입니다.

이렇게 쓰면하루 줄 수 (예시)하루한 달 (매일)
보내기(한→영)만50줄약 50원약 1,500원
보내기 + 파티·공격대·귓말 받기500줄약 500원약 15,000원
대도시 공개 채널까지 전부5,000줄 이상약 5,000원 이상약 15만 원 이상

1달러 = 약 1,400원으로 잡은 대략치입니다. 실제 금액은 대화량·환율·구글 가격 변경에 따라 달라지니, AI Studio의 사용량(Usage) 화면에서 꼭 확인하세요.

추천하는 쓰는 법

  • 무료로 시작: 먼저 무료 키로 써 보세요. 보내기만 쓰거나 파티 대화 정도면 무료 한도 안에서 되는 경우가 많습니다. 무료 하루 한도는 구글이 계정마다 다르게 정해서, AI Studio의 한도(Rate limit) 화면에서 확인할 수 있습니다.
  • 받기는 필요한 채널만: 파티·공격대·귓말처럼 내가 대화하는 채널만 켜 두세요. 거래·공개·파티찾기 같은 대도시 채널은 양이 많아서 비용 대부분이 여기서 나옵니다. 필요할 때만 잠깐 켜는 걸 권합니다. 그래서 최저 단계는 처음 설치하면 파티·공격대·귓말만 켜져 있고, 오늘 쓴 양이 번역창에 표시됩니다.
  • 가운데 파티글과 같이: 파티 대화만 번역해서 화면 가운데에 띄우면, 적은 비용으로 제일 필요한 대화를 놓치지 않습니다.
  • 막히면: 무료 한도를 넘으면 그날은 번역이 멈추고 다음 날 다시 됩니다 (미국 서부 시간 자정 기준). 자주 막히면 그때 유료로 올리면 됩니다.

① 키 만들기 (무료 · 5분)

  1. aistudio.google.com/apikey 에 들어가 구글 계정으로 로그인합니다. 처음이면 이용 약관 동의 창이 뜹니다.
  2. Create API key (API 키 만들기)를 누릅니다. 프로젝트를 고르라고 하면 기본으로 나오는 것을 그대로 고르면 됩니다.
  3. 나온 긴 글자(AIza…로 시작)를 복사합니다.
  4. 번역기 설치 중 뜨는 키 입력 창(나중엔 설정의 Gemini 키 칸)에 붙여 넣으면 끝. 여기까지면 무료로 바로 쓸 수 있습니다.
넣은 키는 내 PC에만 저장됩니다. 키는 이 컴퓨터의 내 설정 파일(%LOCALAPPDATA%\NangmanTranslator)에만 들어가고, 번역할 때 구글 서버로만 직접 보내집니다. 제작자(낭만타우렌)나 다른 곳으로는 보내지 않고, 업데이트를 해도 지워지거나 바뀌지 않습니다. 완전 삭제를 하면 키도 같이 지워집니다.

② 유료로 올리기 (카드 등록 · 선택)

  1. 같은 페이지(API 키 목록) 또는 왼쪽 Projects에서 내 프로젝트 줄의 Set up billing (결제 설정)을 누릅니다.
  2. 처음이면 국가: 대한민국 선택 → 약관 동의 → 이름·주소 같은 연락처 입력.
  3. 결제 수단에 신용카드·체크카드를 등록합니다. 해외 결제가 되는 카드여야 합니다 (VISA·Master 등).
  4. 선불 충전(Prepay) 금액을 정해 결제합니다. 최소 금액이 화면에 나옵니다. 충전한 돈은 쓴 만큼만 줄어들고, 다 쓰면 키가 멈춥니다 (몰래 더 빠져나가지 않음).
  5. 끝나면 프로젝트의 등급이 Free → Paid(Tier 1)로 바뀝니다. 키는 새로 만들 필요 없이 그대로 씁니다.
키는 비밀번호와 같습니다. 다른 사람에게 보내거나 단톡방에 올리지 마세요. 새어 나갔다면 같은 페이지에서 그 키를 지우고(Delete) 새로 만들면 됩니다.

3처음 설정

  1. 바탕화면 바로가기로 번역기 켜기 — 화면 위에 작은 도우미 바(사양 표시 · 번역 버튼 · 사전 업데이트 버튼)가 뜹니다. 도우미 바 옵션에서 윈도우 시작 시 자동 실행을 켜 두면 컴퓨터를 켤 때마다 알아서 켜집니다.
  2. 와우 켜고 채팅창에 /reload — 기본 대화창이 번역기 디자인으로 바뀌고, 미니맵에 번역창·일반 대화창 버튼이 생깁니다.
  3. 탭 설정 — 탭마다 "이 탭에 보일 대화"를 고릅니다. 번역창과 게임 대화창은 탭·설정이 항상 같이 움직입니다.
  4. 가운데 파티글 — 파티 대화를 화면 가운데에 띄우는 기능. 설정 버튼에서 켜고 끄고, 위치·크기를 옮길 수 있습니다.
와우는 테두리 없는 창 모드(전체화면 창모드) 로 켜 주세요. 전체화면 모드에서는 번역창이 게임 위에 안 보입니다.

4평소 사용법

받기 — 영어가 한국어로

[파티] [Hard Truth]: 술사 지금 개쩐다 ㅋㅋ
shammy is nasty rn lol

번역 아래에 영어 원문이 작게 같이 나와서, 보면서 영어 공부도 됩니다. 말투는 "~함 / ~임" 같은 채팅 말투입니다.

보내기 — 한국어가 영어로

번역창 입력줄에 한국어로 치고 Enter → 영어로 바뀌어 게임에 보내집니다. 귓말 답장도 됩니다.

켜기 · 끄기

번역창 아래 [번역 ON] / [번역 안 함] 또는 도우미 바의 번역 버튼. 끄면 게임 기본 대화창으로 돌아갑니다.

보내기를 Gemini로 (선택)

설정에서 Gemini 키를 넣으면 보내기를 Gemini 번역으로 고를 수 있습니다. 문장이 조금 더 자연스러워지고, 보내는 양이 적어서 대부분 무료 한도 안에서 쓸 수 있습니다.

6자주 묻는 문제

번역이 안 떠요
  • 번역기(바탕화면 바로가기)가 켜져 있는지 먼저 확인하세요.
  • 와우에서 /reload 를 한 번 해 주세요.
  • 와우가 전체화면 모드면 테두리 없는 창 모드로 바꿔 주세요.
번역이 느려요
  • 처음 몇 줄은 번역 모델을 불러오느라 느립니다. 조금 지나면 빨라집니다.
  • 대도시에서는 그래픽 메모리를 많이 써서 느려질 수 있습니다. 와우 그래픽 옵션(텍스처 품질)을 한 단계 낮추면 좋아집니다.
탭이 사라졌어요 / 탭 이름이 안 바뀌어요
  • 와우에서 /reload 후 다시 해 보세요. 그래도 안 되면 아래 문의로 알려 주세요.
번역이 이상해요
  • 번역 품질은 사전으로 계속 고칩니다. 이상한 번역 화면을 캡처해서 보내 주시면 사전에 반영됩니다. 반영되면 [사전 업데이트]로 받으세요.

7완전 삭제

설치 폴더의 완전삭제.bat (또는 설정의 [완전 삭제]) 한 번으로 다 지웁니다.

  • 프로그램 폴더 · 바탕화면 바로가기 · 내 설정
  • 인게임 애드온 (다른 애드온은 그대로)
  • 번역 모델 · Ollama는 다른 데서도 쓰는지 묻고 원하면 같이 삭제

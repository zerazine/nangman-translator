낭만타우렌 와우 포에버 번역기

북미 서버 영어 채팅을 게임 위에서 바로 한국어로 보고, 한국어로 치면 영어로 보내 주는 무료 번역 프로그램입니다. 번역은 내 PC 안에서 돌아가서 돈이 들지 않습니다.

특징저작권내 PC 버전설치처음 설정사용법업데이트자주 묻는 문제삭제문의후원

번역모델 소개

와우 전용으로 학습한 번역 모델일반 번역기가 아니라, 실제 북미 와우 채팅 1만 줄 이상으로 따로 가르친 모델입니다. 탱·힐·딜, 인던 줄임말, 레이드 콜, 게이머 말투까지 와우 맥락으로 알아듣습니다.
계속 진화하는 번역제작자가 매일 실제 게임에서 쓰며 틀린 번역을 고칩니다. 고친 사전은 번역기가 알아서 받아 적용하니(자동 업데이트), 따로 누를 것 없이 쓸수록 더 와우다운 번역이 됩니다.
내 PC에서 돌아가는 무료 번역번역이 내 컴퓨터 안에서 이루어져 사용료가 없고, 채팅이 바깥 서버로 나가지 않습니다 (Gemini 버전 제외).

저작권 안내

본 북미섭 와우 포에버 전용 번역프로그램의 저작권은 제작자 낭만타우렌 (배틀태그 하르만#31615)에 있으며 어떤 방식으로도 수정과 재배포가 불가합니다.

버튼 한 번으로 확인

받기 전에 눌러 보세요. 브라우저가 알려 주는 그래픽카드 이름으로 버전을 추천합니다. 아무것도 받거나 설치하지 않습니다.

직접 확인하는 법 (작업 관리자)

  1. 키보드에서 Ctrl + Shift + Esc → 작업 관리자
  2. 위쪽 성능 탭 → 왼쪽 아래 GPU
  3. 오른쪽의 전용 GPU 메모리 숫자 (예: 12.0GB)

숫자가 8GB 이상이면 Gemma 버전, 그보다 작으면 Gemini 버전을 받으세요. AMD 그래픽카드는 Gemini 버전을 권합니다. 설치할 때도 설치 파일이 한 번 더 확인해 줍니다.

⚠ 그래픽 메모리 8GB라면 꼭 읽어 주세요

Gemma 버전은 번역 모델이 와우와 같은 그래픽카드 메모리를 나눠 씁니다 (번역 모델 약 3.5GB). 8GB 카드에서는 와우에 남는 메모리가 4GB 남짓이라, 그래픽 설정이 높으면 이런 일이 생길 수 있습니다.

  • 게임 화면이 버벅이거나 순간적으로 멈춤 (특히 대도시, 먼 풍경이 보이는 곳)
  • 번역이 갑자기 몇 초씩 늦게 뜸

이럴 땐 와우 포에버 Options(설정) → Graphics(그래픽)에서 아래 순서대로 낮춰 보세요. 위쪽일수록 효과가 큽니다. 한 가지씩 바꾸고 확인하면 됩니다.

  1. zip 받기 — 위에서 내 버전 카드의 [받기]를 눌러 구글 드라이브에서 받습니다.
  2. 압축 끝까지 풀기 — zip을 오른쪽 클릭 → 모두 압축 풀기. zip 안에서 바로 실행하면 안 됩니다.
  3. 설치 파일 열기 — 낭만타우렌_와우포에버번역기_설치.exe를 두 번 누릅니다. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요. (처음 보는 프로그램이라 윈도우가 한 번 묻는 것입니다)
  4. [설치] 누르기 — 큰 [설치] 버튼 하나면 됩니다. 와우 폴더 찾기, 번역 엔진(Ollama) 받기, 번역 모델 받기, 게임 애드온까지 알아서 설치합니다. Gemma 버전은 이때 약 5GB를 인터넷에서 받아서, 인터넷 속도에 따라 5~20분쯤 걸립니다. 창에 받는 양과 남은 시간이 나오니 그대로 두세요. 중간에 끊겨도 알아서 이어 받습니다. Gemini 버전은 이때 Gemini 키를 넣는 창이 뜹니다 (키 받는 법).
  5. "완료"가 뜨면 끝 — 마지막에 번역 한 줄(예: LF1M tank → 탱 1명 구함)을 시험해 보고 성공해야 완료가 뜹니다. 바탕화면에 번역기 아이콘이 생깁니다.
프로그램은 C:\낭만타우렌_번역기 에 설치되고, 바탕화면에는 바로가기만 생깁니다.

Gemini 키 받는 법 (Gemini 버전)

Gemini는 구글의 번역 AI입니다. 키를 넣으면 번역기가 구글 서버로 채팅을 보내 번역합니다. 무료로도 쓸 수 있지만, 하루에 보낼 수 있는 양이 정해져 있어서 공개 채널까지 다 번역하면 금방 막힙니다. 오래 쓰실 거면 유료(결제 등록)를 권합니다.

예상 금액 (유료일 때)

번역기는 한 줄을 번역할 때 와우 용어 사전·말투 지시문을 같이 보내서, 한 줄에 대략 입력 2,000토큰 + 출력 40토큰쯤 씁니다. Gemini 3.5 Flash-Lite 유료 가격(입력 100만 토큰당 0.30달러 · 출력 100만 토큰당 2.50달러)으로 계산하면 한 줄에 약 1원입니다.

1달러 = 약 1,400원으로 잡은 대략치입니다. 실제 금액은 대화량·환율·구글 가격 변경에 따라 달라지니, AI Studio의 사용량(Usage) 화면에서 꼭 확인하세요.

추천하는 쓰는 법

  • 무료로 시작: 먼저 무료 키로 써 보세요. 보내기만 쓰거나 파티 대화 정도면 무료 한도 안에서 되는 경우가 많습니다. 무료 하루 한도는 구글이 계정마다 다르게 정해서, AI Studio의 한도(Rate limit) 화면에서 확인할 수 있습니다.
  • 받기는 필요한 채널만: 파티·공격대·귓말처럼 내가 대화하는 채널만 켜 두세요. 거래·공개·파티찾기 같은 대도시 채널은 양이 많아서 비용 대부분이 여기서 나옵니다. 필요할 때만 잠깐 켜는 걸 권합니다. 그래서 최소 사양는 처음 설치하면 파티·공격대·귓말만 켜져 있고, 오늘 쓴 양이 번역창에 표시됩니다.
  • 가운데 파티글과 같이: 파티 대화만 번역해서 화면 가운데에 띄우면, 적은 비용으로 제일 필요한 대화를 놓치지 않습니다.
  • 막히면: 무료 한도를 넘으면 그날은 번역이 멈추고 다음 날 다시 됩니다 (미국 서부 시간 자정 기준). 자주 막히면 그때 유료로 올리면 됩니다.

① 키 만들기 (무료 · 5분)

  1. aistudio.google.com/apikey 에 들어가 구글 계정으로 로그인합니다. 처음이면 이용 약관 동의 창이 뜹니다.
  2. Create API key (API 키 만들기)를 누릅니다. 프로젝트를 고르라고 하면 기본으로 나오는 것을 그대로 고르면 됩니다.
  3. 나온 긴 글자(AIza…로 시작)를 복사합니다.
  4. 번역기 설치 중 뜨는 키 입력 창(나중엔 설정의 Gemini 키 칸)에 붙여 넣으면 끝. 여기까지면 무료로 바로 쓸 수 있습니다.
넣은 키는 내 PC에만 저장됩니다. 키는 이 컴퓨터의 내 설정 파일(%LOCALAPPDATA%\NangmanTranslator)에만 들어가고, 번역할 때 구글 서버로만 직접 보내집니다. 제작자(낭만타우렌)나 다른 곳으로는 보내지 않고, 업데이트를 해도 지워지거나 바뀌지 않습니다. 완전 삭제를 하면 키도 같이 지워집니다.

② 유료로 올리기 (카드 등록 · 선택)

  1. 같은 페이지(API 키 목록) 또는 왼쪽 Projects에서 내 프로젝트 줄의 Set up billing (결제 설정)을 누릅니다.
  2. 처음이면 국가: 대한민국 선택 → 약관 동의 → 이름·주소 같은 연락처 입력.
  3. 결제 수단에 신용카드·체크카드를 등록합니다. 해외 결제가 되는 카드여야 합니다 (VISA·Master 등).
  4. 선불 충전(Prepay) 금액을 정해 결제합니다. 최소 금액이 화면에 나옵니다. 충전한 돈은 쓴 만큼만 줄어들고, 다 쓰면 키가 멈춥니다 (몰래 더 빠져나가지 않음).
  5. 끝나면 프로젝트의 등급이 Free → Paid(Tier 1)로 바뀝니다. 키는 새로 만들 필요 없이 그대로 씁니다.
키는 비밀번호와 같습니다. 다른 사람에게 보내거나 단톡방에 올리지 마세요. 새어 나갔다면 같은 페이지에서 그 키를 지우고(Delete) 새로 만들면 됩니다.

3처음 설정

  1. 번역기 켜기 — 바탕화면의 낭만타우렌 와우 포에버 번역기를 켜면 처음 한 번 저작권 안내 창이 뜹니다. [확인]을 누르면 화면 위쪽에 도우미 바(사양 표시 · 번역 · 사전 업데이트 · 설정 버튼)가 생깁니다. 도우미 바 [설정]에서 윈도우 시작 시 자동 실행을 켜 두면 컴퓨터를 켤 때마다 알아서 켜집니다.
  2. 와우 켜고 채팅창에 /reload — 기본 대화창이 번역기 디자인으로 바뀌고, 미니맵 옆에 둥근 버튼 두 개(번역 · 대화창)가 생깁니다.
  3. 탭 설정 — 탭을 오른쪽 클릭해서 "이 탭에 보일 대화"(파티·길드·귓말·거래 등)를 고릅니다. 번역대화창과 게임 대화창은 탭·설정이 항상 같이 움직입니다.
와우는 테두리 없는 창 모드(전체화면 창모드) 로 켜 주세요. 전체화면 모드에서는 번역창이 게임 위에 안 보입니다.

4사용법

번역 켜고 끄기

미니맵 옆 둥근 버튼 두 개입니다. 번역 버튼(가A)을 누르면 번역대화창이 뜨고, 대화창 버튼을 누르면 번역을 끄고 와우 기본 대화창으로 돌아갑니다. 켜진 쪽에 금빛이 들어오고, 꺼진 쪽은 회색입니다. 번역대화창 안의 [번역 ON] 버튼과 도우미 바의 번역 버튼도 같은 스위치입니다.

입력칸은 화면 가운데 파티글 바로 아래에 뜹니다. 받은 귓말에 바로 답장도 됩니다.

⚠ Enter 후 0.5~1초쯤 뒤에 게임 채팅으로 나갑니다

번역기는 게임 밖에서 돌아가는 프로그램이라, Enter를 누르면 ① 영어로 번역하고 ② 와우 채팅 입력칸에 대신 넣어서 보내는 두 단계를 거칩니다. 그래서 내 글은 번역창에 바로 보이지만, 실제 게임 채팅에 올라가기까지 잠깐 틈이 있습니다. 고장이 아니니 걱정하지 마세요.

  • 그 잠깐 동안(약 1초)은 다른 키를 누르거나 창을 바꾸지 마세요. 번역기가 게임 입력칸에 글을 넣는 중이라, 끼어든 키가 같이 들어갈 수 있습니다.
  • 보내는 순간 복사·붙여넣기(클립보드)를 잠깐 빌려 쓰고 바로 원래대로 돌려놓습니다.
  • Gemini 보내기를 고르면 번역 시간이 조금 더 걸릴 수 있습니다.

가운데 파티글 — 위치 · 크기 바꾸기

파티 대화를 화면 가운데에 크게 띄워 주는 기능입니다. 번역대화창의 ⚙ 설정 → 가운데 파티글 → 위치·크기 [조절하기]. 점선 칸을 끌어서 옮기고, 오른쪽 아래 네모를 끌어 크기를 바꾼 뒤 [완료]. 줄 수 · 글자 크기도 여기서 바꿉니다. 켜고 끄기도 같은 곳에 있습니다.

대화창 옮기기 · 크기 바꾸기

번역대화창 위쪽 탭 줄을 끌면 이동, 맨 오른쪽 아래 구석의 금색 빗금(마우스를 올리면 보임)을 끌면 크기가 바뀝니다. 와우 대화창을 직접 옮겨도 번역대화창이 같은 자리·크기로 따라옵니다.

Ctrl + 오른쪽 클릭 = 위치·크기 잠금 / 풀기. 잠겨 있으면 크기 빗금이 안 보이니, 빗금이 안 보일 때는 먼저 Ctrl + 오른쪽 클릭으로 풀어 주세요. 엉망이 되면 ⚙ 설정의 [대화창 위치·크기 처음대로].

사용법이 생각 안 나면 번역대화창의 ⚙ 설정 → 맨 아래 [사용법]을 누르세요. 대화창 안에 사용법이 바로 뜹니다.

보내기 번역 고르기 (자체 / Gemini)

기본은 자체 번역이라 아무것도 안 해도 됩니다. 더 자연스러운 영어를 원하면 ⚙ 설정 → 보내기 번역에 Gemini 키를 넣고 [저장]한 뒤 Gemini 번역을 고르세요. 키가 틀리거나 한도를 넘으면 알아서 자체 번역으로 보내고 작게 알려 줍니다.

6자주 묻는 문제

번역이 안 떠요
  • 번역기가 꺼져 있을 수 있어요. 화면에 도우미 바가 안 보이면 바탕화면의 낭만타우렌 와우 포에버 번역기 아이콘을 더블클릭해 다시 켜 주세요. (매번 켜기 귀찮으면 도우미 바 [설정] → 윈도우 시작 시 자동 실행)
  • 도우미 바에 번역이 켜져 있는지, 미니맵 번역 버튼(가A)에 금빛이 들어와 있는지 확인하세요.
  • 와우에서 /reload 를 한 번 해 주세요.
  • 와우가 전체화면 모드면 테두리 없는 창 모드로 바꿔 주세요.
번역이 느려요
  • 처음 몇 줄은 번역 모델을 불러오느라 느립니다. 조금 지나면 빨라집니다.
  • 대도시에서는 그래픽 메모리를 많이 써서 느려질 수 있습니다. 와우 포에버 그래픽 설정을 조금 낮추면 좋아집니다 (추천 설정).
탭이 사라졌어요 / 탭 이름이 안 바뀌어요
  • 와우에서 /reload 후 다시 해 보세요. 그래도 안 되면 아래 문의로 알려 주세요.
번역이 이상해요
  • 번역 품질은 사전으로 계속 고칩니다. 이상한 번역 화면을 캡처해서 보내 주시면 사전에 반영됩니다. 반영되면 번역기가 자동으로 받아 적용합니다.
대화창이 이상하게 겹쳐요
  • 다른 대화창 애드온(Prat, ElvUI 대화창 등)과 같이 쓰면 부딪힙니다. 그 애드온을 끄고 쓰세요.
다시 설치하고 싶어요
  • 설치 파일을 다시 누르면 됩니다. 이미 깔린 건 건너뛰고 빠진 것만 채웁니다. 내 설정은 그대로 남습니다.

7완전 삭제

아래 세 곳 중 아무 데서나 열고 [완전 삭제]를 누르면 됩니다.

  • 시작 메뉴 → 낭만타우렌 와우 포에버 번역기 삭제
  • 윈도우 설정 → 앱 → 낭만타우렌 와우 포에버 번역기 → 제거
  • 설치 파일을 다시 열기

프로그램, 번역 모델, 게임 애드온, 내 설정(Gemini 키 포함), 바탕화면 아이콘까지 모두 지웁니다. 와우와 다른 애드온은 건드리지 않습니다.

삭제하기 전에 와우를 꺼 주세요. 게임이 켜져 있으면 애드온 파일을 못 지워서 "와우를 꺼 주세요"라고 알려 줍니다. 번역 엔진(Ollama)은 번역기가 깔았고 다른 데서 안 쓸 때만 같이 지웁니다.

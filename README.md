# 낭만타우렌 와우 포에버 번역기

북미 와우 포에버(WoW Forever) 채팅을 한국어로, 내가 쓴 한국어를 영어로 바꿔 주는 무료 번역기입니다.
번역은 **내 컴퓨터 안에서**(로컬 AI · Ollama) 돌아가고, 게임 채팅창 자리에 번역 대화창을 띄워 줍니다.

- 설명서 · 다운로드: https://zerazine.github.io/nangman-translator/
- 제작: 낭만타우렌 (배틀태그 하르만#31615)

---

## 이 저장소에 공개된 것

설치하면 실제로 돌아가는 파일이 그대로 올라가 있습니다. 누구나 열어서 확인할 수 있어요.

| 위치 | 내용 |
|---|---|
| `app/<버전>/app/NangmanTranslator.ps1` | 번역기 프로그램 본체 (PowerShell 글자 파일 · 메모장으로 열림) |
| `app/<버전>/app/ftr/*.cs` | 게임 화면 신호를 읽는 부분 · 음성 번역 부분 (C# 원본 · 실행할 때 그 자리에서 컴파일) |
| `app/<버전>/addon/NangmanTranslator/` | 게임 애드온 (Lua) |
| `installer/` | 설치 프로그램(.exe)의 **원본 코드** (C#) · 만드는 방법 |
| `app/<버전>/app/Uninstall.exe` · `NangmanTranslator.exe` | 설치 프로그램과 같은 파일 (삭제용 · 창 없이 켜는 실행기 `/run`) |
| `app/version.json` | 업데이트 파일 목록과 **SHA256 검사값** — 받은 파일이 하나라도 바뀌면 번역기가 적용하지 않음 |
| `app/control.json` | 제작자 알림판 (아래 설명) |
| `.github/` | 자동 시험 코드 |
| `download/` | 설치 꾸러미 (zip) |

**공개하지 않는 것**
- `dict2/dict.bin` 번역 사전 — 직접 만든 사전이라 암호화해 두었습니다. 번역기가 실행 중에만 풀어서 씁니다.
- 번역 모델 파일 — 크기가 커서 따로 받습니다 (`model/model.json`의 주소·검사값으로 받고 맞는지 확인).

## 자동 시험 (GitHub Actions)

업데이트를 올리기 전마다 깃헙 서버(Windows · PowerShell 5.1, 사용자와 같은 환경)에서 자동으로 시험합니다.
결과는 이 저장소의 **Actions** 탭에서 누구나 볼 수 있어요.

- 설치 → 다시 설치(덮어쓰기) → 완전 삭제 (프로그램·애드온·바로가기·앱 목록·번역 엔진까지 남는 것 없는지)
- 한글 이름 사용자 폴더 설치
- 옛 버전(1.16부터)마다 실제 업데이트 코드로 최신 버전을 한 번에 받는지
- 프로그램 문법 · 사전 · 음성 파일 검사

## 이 번역기가 인터넷으로 보내는 것 (전부)

채팅 내용 · 캐릭터 이름 · 배틀태그 · 계정 정보는 **보내지 않습니다.**

| 언제 | 어디로 | 보내는 것 |
|---|---|---|
| 업데이트 확인 (켤 때 · 몇 시간마다) | 이 저장소 (GitHub Pages) | 받기만 함 (`version.json` · `control.json` · 사전) |
| 하루 한 번 사용 통계 | 제작자 Supabase | 무작위 번호(설치 때 만든 것) · 버전 · 젬마/외부 API 구분 |
| 사전 열쇠 받기 | 제작자 Supabase | 무작위 번호 · 버전 |
| **번역 제보 버튼을 직접 눌렀을 때만** | 제작자 Supabase | 그 한 줄의 원문 · 번역 · 고친 번역(쓴 경우) · 채널 종류(파티·공개 등) · 버전 |
| 외부 API를 직접 켠 경우만 | 사용자가 고른 AI 회사 (제미나이 · Claude · ChatGPT 방식 API · 사용자 본인 키) | 번역할 그 말 |

- Supabase 키는 프로그램 안에 그대로 보이는 **공개용 키**입니다. 기록을 추가하는 것만 되고, 읽기·수정·삭제는 안 됩니다.
- 인터넷이 안 되면 통계·제보는 조용히 건너뛰고, 번역은 그대로 됩니다.
- 위 표는 `NangmanTranslator.ps1`에서 `supabase`, `googleapis`로 검색하면 전부 확인할 수 있습니다.

## 제작자 알림판 (`app/control.json`)

번역기가 켤 때와 3시간마다 이 공개 파일을 읽습니다. 지금 무엇이 적혀 있는지 누구나 볼 수 있어요.

- `notice`: 대화창에 한 번 띄우는 공지
- `minVer`: 너무 옛 버전에 '업데이트 필요' 안내
- `off` / `blockIds`: 서비스를 멈추거나 특정 번호만 멈추는 칸 (비어 있으면 아무 영향 없음)

## 설치 프로그램이 하는 일

원본: `installer/Setup.cs`

1. 프로그램을 `%LOCALAPPDATA%\Programs\NangmanTranslator` 에 복사 (관리자 권한 필요 없음)
2. 게임 애드온을 와우 포에버 `Interface\AddOns` 에 복사
3. 번역 엔진 Ollama 설치 (Ollama 공식 GitHub · ollama.com에서 받음) · 번역 모델 받기 (검사값 확인)
4. 바탕화면 · 시작 메뉴 바로가기, Windows '앱 목록'에 등록 (여기서 제거 가능)
5. 윈도우 시작 시 자동 실행은 **사용자가 번역기에서 켤 때만**

삭제하면 프로그램 폴더 · 애드온 · 바로가기 · 앱 목록 · Ollama와 모델까지 지웁니다.

## 자료 출처

사전의 아이템·NPC 등 게임 고유명사(영어·한국어 이름)는 블리자드 공식 API(Battle.net Game Data API)에서 받은 블리자드 엔터테인먼트의 게임 데이터입니다. World of Warcraft 및 관련 이름의 권리는 Blizzard Entertainment에 있습니다. 그 밖의 사전 내용(은어·표현·번역문 등)은 제작자가 직접 모으고 번역한 자료입니다.
